# Realtime Lab Files 0.5.0-alpha.14

新增手机及桌面设备远程同步诊断：匿名设备ID、系统、插件版本、前后台、队列分类计数、失败/冲突数、最近确认和上报时间，以及本地快照是否匹配当前服务器。仅连接、前台、空队列、处理完成、无错误/冲突，且确认与上报均在30秒内时标为最近上报已同步。离线、过期、后台和旧版未上报均待确认。不是未来编辑或未保存按键不丢失的保证。

诊断仅存在于原独立服务器内存，最多64设备、24小时过期，重启即清空；不存文件名、正文、附件、原始错误、令牌、IP或用户名。使用既有鉴权与公网路由，持有原库令牌可查询；原内容/历史/快照/队列/设置不重置。新增匿名ID保存在本机插件配置中。

手机需更新 alpha.14 并保持前台，约10秒内上报；无需重复输入。设置或命令“查看设备远程同步诊断”，也可使用 source.zip 内 scripts/device-diagnostics.mjs，只通过环境变量指定已有地址及私有令牌文件。旧客户端保持同步兼容，但无法上报内部队列。

188 项完整测试、类型检查和构建通过；公网软件诊断端验证计数、完成判断及未鉴权拒绝。真机上报待手机更新后验收。只用于 Realtime-Lab-V3-Files- 独立测试库；Mac 本轮未更换插件，服务端已备份并更新。

source.zip 为源码。npm install; npm run typecheck; node --test --test-concurrency=2 test/*.test.mjs; npm run build:v3-files。容量及协议限制见 V3-FILES.md。
